Roatán reef cam search

Text search over viewer-captioned snapshots from two fixed underwater cameras at Utopia Village, Roatán. Each query is answered three ways, so you can see what a few thousand captions teach a frozen image-text model about one camera.

SigLIP2, frozen

The base model as released (base/16, 256 px). No camera-specific training.

Two linear maps

One linear map on the query embedding and one on the image embedding, fitted to this camera's captions.

Two maps over sets

The same two maps applied to every phrase of the query and every patch of the image; each phrase is matched to its best patch.

A green outline means the viewer's own caption for that frame contains the query phrases. It is a rough guide: viewers caption one thing per snapshot, so a correct fish in an uncaptioned frame is not outlined.

By default the search covers held-out frames only: neither the frame nor its caption was seen when the maps were fitted. Typed queries run the SigLIP2 text encoder in your browser (a 370 MB download the first time); the suggested phrases work without it.

Images and captions come from the explore.org snapshot gallery. Thumbnails load from explore.org and each one links to the original snapshot.
